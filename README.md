# Sistemas del Cuerpo Humano

## Descripción
Aplicación de Realidad Aumentada desarrollada con AR.js y A-Frame que permite visualizar modelos 3D de los sistemas del cuerpo humano

## Tecnologías
- AR.js
- A-Frame

## Problema Abordado
Dificultad en la comprensión tridimensional de los sistemas anatómicos en métodos tradicionales.

## Solución
La aplicación permite:
- Visualizar modelos 3D

## Cómo ejecutar
1. Abre el siguiente enlace https://alejandraalvarado03.github.io/Taller_AR/
2. Permitir acceso a la cámara.
3. Enfocar el marcador correspondiente.
